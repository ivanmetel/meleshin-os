# Симуляция: Карточка проекта

Симуляция новой карточки проекта (переработка страницы). Назначение —
показать переработанную карточку до внесения изменений в производственную CRM.

Основа — ТЗ "Карточка проекта" от 18.09.2026: шапка по ТЗ 2.2, 8 табов,
по умолчанию открыт "Основное" (ТЗ 2.1). Ролевой модели нет — всем видно всё.
Разделы, помеченные в ТЗ [ ], показывают состояние "ждёт наполнения".

## Данные

Все данные демонстрационные: вымышленный проект "2607. Polis Apartment",
вымышленные клиент, прораб, подрядчики и итоги. Реальная информация
в репозитории не содержится.

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```
python3 -m http.server 8080
```

и открыть http://localhost:8080
