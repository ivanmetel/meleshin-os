# Симуляция: Карточка проекта + Все проекты

Симуляция переработки карточки проекта и списка проектов. Назначение —
показать переработанную карточку до внесения изменений в производственную CRM.

Основа — ТЗ "Карточка проекта" от 18.09.2026 (правки 22.09): шапка по ТЗ 2.1,
8 табов (ТЗ 2.2), по умолчанию открыт "Основное" (ТЗ 1). Страница "Все проекты" —
список карточек с фильтром по этапу (ТЗ 2.1 п.3: Предпроектные работы /
СМР и отделочные работы / Пост-проектные работы) и кнопкой "Добавить проект" (ТЗ 1).
Таб "Основное" (ТЗ 2.2.1): информация шапки не дублируется, видны "Вид работ"
и "Заметки"; "Редактировать" (ТЗ 2.2.1.1) — всплывающее окно со всеми полями,
включая "Добавить участника"; "История" — открывает/скрывает лог изменений.
На каждой карточке слева — кнопка "Все проекты".
Ролевой модели нет — всем видно всё. Разделы, помеченные в ТЗ [ ], показывают
состояние "ждёт наполнения". Правки демо хранятся в памяти страницы до перезагрузки.

## Данные

Все данные демонстрационные: вымышленные проекты "2608. Peyia Villa",
"2607. Polis Apartment", "2604. Nicosia Office", вымышленные клиенты, прорабы,
подрядчики и итоги. Реальная информация в репозитории не содержится.

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```
python3 -m http.server 8080
```

и открыть http://localhost:8080

## Маршруты

| Адрес | Страница |
|---|---|
| `#/vse-proekty` | Все проекты (фильтр этапов) |
| `#/<проект>/<таб>` | Карточка проекта, например `#/2607-Polis-Apartment/osnovnoe` |
| `#/<таб>` | Карточка проекта по умолчанию (2607) — прежний формат ссылок |

## Файлы

| Файл | Роль |
|---|---|
| index.html | каркас страницы |
| styles.css | оформление |
| app.js | маршрутизация и рендер: список, шапка, табы, разделы |
| data.js | демо-данные проектов |
