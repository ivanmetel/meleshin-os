# Симуляция: Карточка проекта (переработка по ТЗ)

Симуляция новой карточки проекта по ТЗ `../2026-09-18-meleshin-os-project-card-tz.md`.
Назначение — показать переработку страницы до внесения изменений в производственную CRM.

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```
python3 -m http.server 8080
```

и открыть http://localhost:8080

## Вид

Новая карточка проекта по ТЗ (раздел 2): шапка по ТЗ 2.2, 8 табов,
по умолчанию открыт "Основное" (ТЗ 2.1). Ролевой модели нет — всем видно всё.

Разделы, помеченные в ТЗ [ ], показывают состояние "ждёт наполнения" с подсказкой,
какие данные проекта уже доступны в CRM.

## Данные

Реальная выгрузка meleshin.cloud через API 18.09.2026,
проект "Coffee bar Paphos" (id 11):

- шапка, итоги, файлы — из API;
- фото и видео — горячие ссылки на производственные файлы meleshin.cloud, в репозиторий не копируются;
- сводка финансов собрана из итогов проекта (операции в выгрузку не попали);
- задач за проектом в CRM не закреплено — раздел показывает реальное пустое состояние.

Название в демо приведено к формату ТЗ 2.2 п. 3: "11. Paphos Coffee Bar",
машинная форма "11-Paphos-Coffee-Bar" (в заголовке вкладки браузера).

## Файлы

| Файл | Роль |
|---|---|
| index.html | каркас страницы |
| styles.css | оформление (Inter, палитра производственной CRM) |
| app.js | рендер: шапки, табы, разделы |
| data.js | выгрузка данных проекта (фикстура) |
