# Симуляция: Карточка проекта + Все проекты

Симуляция переработки карточки проекта и списка проектов. Назначение —
показать переработанную карточку до внесения изменений в производственную CRM.

Основа — ТЗ "Карточка проекта" от 18.09.2026 (правки 22.09) и рекомендации
к ТЗ от 23.09.2026. Шапка — по ТЗ 2.1, реквизиты и участники редактируются
кнопкой "Редактировать" в шапке. Пять табов: Основное, Задачи, Документы,
График (содержимое — отдельное ТЗ), Финансы; "Тендер", "Фото и видео",
"Кабинет клиента" в этой версии скрыты (рекомендации, раздел 1).

- Основное: состав работ и его конструктор — "Редактировать состав"
  (добавление, изменение, перемещение, исключение строк; "Весь объект" —
  общие работы). После сохранения состав попадает в рабочие редакции обоих
  бюджетов; несохранённые изменения в бюджеты не попадают.
- Задачи: # / Задача / Автор / Дата создания / Дедлайн / Ответственный /
  Статус; фильтры — статус, ответственный, просроченные.
- Документы: один реестр — представления Все / Входящие / Исходящие /
  Внутренние; тип, направление и статус — отдельные признаки; жизненный
  цикл по направлению (Получен → В обработке → Обработан; Черновик →
  Готов к отправке → Отправлен; Черновик → Утверждён).
- Финансы: Сводный → Внутренний бюджет → Бюджет клиента → Фактический
  труд по табелям → Финансовые операции. Состав и количества бюджетов —
  из "Основного"; внутренняя и клиентская цены хранятся независимо;
  зафиксированные версии (исходный бюджет, согласованный бюджет клиента)
  не изменяются при редактировании. Сводные показатели вычисляются из
  источников: версии, период факта и неполнота указаны рядом с числом.
- Страница "Все проекты" — фильтр по этапу (ТЗ 2.1 п.3) и кнопка
  "Добавить проект" (ТЗ 1).

Ролевой модели нет — всем видно всё. Правки демо хранятся в памяти страницы
до перезагрузки.

## Данные

Все данные демонстрационные: вымышленные проекты "2608. Peyia Villa",
"2607. Polis Apartment", "2604. Nicosia Office", вымышленные клиенты, прорабы,
подрядчики и суммы. Реальная информация в репозитории не содержится.

## Запуск

Открыть `index.html` в браузере, либо поднять локальный сервер:

```
python3 -m http.server 8080
```

и открыть http://localhost:8080

## Маршруты

| Адрес | Страница |
|---|---|
| `#/vse-proekty` | Все проекты (фильтр этапов) |
| `#/<проект>/<таб>` | Карточка проекта, например `#/2607-Polis-Apartment/osnovnoe` |
| `#/<таб>` | Карточка проекта по умолчанию (2607) — прежний формат ссылок |

Табы: `osnovnoe`, `zadachi`, `dokumenty`, `grafik`, `finansy`.
